# dixi extension

## Purpose

`dixi extension`: Add, list or remove local data-only extensions that add operations (ADR-109).

Generated by `scripts/build-cli-reference.py` from the argument parser and the message catalog; do not edit by hand.

## Usage

```text
dixi extension <command>
dixi extension add <folder>
dixi extension list
dixi extension remove <id>
```

The global options `--lang` and `--json` go before the command; see the [CLI reference](index.md).

## Options

- `--help`, `-h` — Show this help.

## Subcommands

### `dixi extension add`

Install an extension folder (extension.json and operations/en|es/*.md) for the project's agent.

**Arguments**

- `folder` — Folder of the extension on the local disk.

**Options**

- `--help`, `-h` — Show this help.

### `dixi extension list`

List the installed extensions.

**Options**

- `--help`, `-h` — Show this help.

### `dixi extension remove`

Remove an extension: deletes only the files it installed that you have not edited.

**Arguments**

- `id` — Extension id.

**Options**

- `--help`, `-h` — Show this help.
