# dixi pr-size

## Purpose

`dixi pr-size`: Measure the current branch against a base: changed lines, without documentation, lockfiles, generated files or tests.

Generated by `scripts/build-cli-reference.py` from the argument parser and the message catalog; do not edit by hand.

## Usage

```text
dixi pr-size [--base <base>] [--max <limit>]
```

The global options `--lang` and `--json` go before the command; see the [CLI reference](index.md).

## Options

- `--help`, `-h` — Show this help.
- `--base <base>` — Base branch or commit (default: main).
- `--max <limit>` — Maximum counted lines (default: 1500).
