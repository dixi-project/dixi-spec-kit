# dixi preset

## Purpose

`dixi preset`: Add, list or remove local data-only presets that override kit texts (ADR-109).

Generated by `scripts/build-cli-reference.py` from the argument parser and the message catalog; do not edit by hand.

## Usage

```text
dixi preset <command>
dixi preset add <folder>
dixi preset list
dixi preset remove <id>
```

The global options `--lang` and `--json` go before the command; see the [CLI reference](index.md).

## Options

- `--help`, `-h` — Show this help.

## Subcommands

### `dixi preset add`

Apply a preset folder (preset.json, operations/en|es, templates/en|es) to unedited kit files.

**Arguments**

- `folder` — Folder of the preset on the local disk.

**Options**

- `--help`, `-h` — Show this help.

### `dixi preset list`

List the installed presets.

**Options**

- `--help`, `-h` — Show this help.

### `dixi preset remove`

Remove a preset: restores the kit text only where the preset text is unchanged.

**Arguments**

- `id` — Preset id.

**Options**

- `--help`, `-h` — Show this help.
