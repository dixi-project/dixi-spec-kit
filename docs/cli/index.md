# CLI reference

## Purpose

Every `dixi` terminal command with its arguments, options and exit codes, so that it can be scripted safely. The operations that run inside an agent are in the command reference.

Generated by `scripts/build-cli-reference.py` from the argument parser and the message catalog; do not edit by hand.

## Usage

```text
dixi [--lang {es,en}] [--json] <command>
```

## Global options

Write them before the command, for example `dixi --lang es --json check`.

- `--help`, `-h` — Show this help.
- `--version` — Show the installed version.
- `--lang {es,en}` — Language for messages and new documents.
- `--json` — Emit structured JSON results.

## Commands

- [`dixi init`](init.md) — Create a documentary baseline in a new or empty destination.
- [`dixi doctor`](doctor.md) — Diagnose local requirements without network or credentials.
- [`dixi check`](check.md) — Check structure and traceability without executing code.
- [`dixi workflow`](workflow.md) — Consult procedures and prepare context without running an agent.
- [`dixi upgrade`](upgrade.md) — Preview (--dry-run) or apply (--apply) what this kit version changes in the project.
- [`dixi extension`](extension.md) — Add, list or remove local data-only extensions that add operations (ADR-109).
- [`dixi preset`](preset.md) — Add, list or remove local data-only presets that override kit texts (ADR-109).
- [`dixi placeholders`](placeholders.md) — List the {{pending: …}} markers left in the project's documents.
- [`dixi pr-size`](pr-size.md) — Measure the current branch against a base: changed lines, without documentation, lockfiles, generated files or tests.
- [`dixi mode`](mode.md) — Show MODE and, for mvp, the promotion items without evidence. Read-only: it never changes MODE.

## Exit codes

| Code | Meaning |
|---|---|
| 0 | Success. |
| 1 | Invalid content: the project does not pass a check. |
| 2 | Usage error or missing project. |
| 3 | Occupied or unsafe destination. |
| 4 | Unsupported version or platform. |
| 5 | Input or output failure. |
