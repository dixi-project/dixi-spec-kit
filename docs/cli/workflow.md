# dixi workflow

## Purpose

`dixi workflow`: Consult procedures and prepare context without running an agent.

Generated by `scripts/build-cli-reference.py` from the argument parser and the message catalog; do not edit by hand.

## Usage

```text
dixi workflow <command>
dixi workflow list
dixi workflow show <operation>
dixi workflow prepare <operation> --target <target> --request <request>
```

The global options `--lang` and `--json` go before the command; see the [CLI reference](index.md).

## Subcommands

### `dixi workflow list`

List available shared procedures.

**Options**

- `--help`, `-h` — Show this help.

### `dixi workflow show`

Show a procedure's inputs, steps, outputs and gates.

**Arguments**

- `operation` — Shared procedure. One of the operations listed by `dixi workflow list`.

**Options**

- `--help`, `-h` — Show this help.

### `dixi workflow prepare`

Prepare instructions and a target manifest; no writes or AI execution.

**Arguments**

- `operation` — Shared procedure. One of the operations listed by `dixi workflow list`.

**Options**

- `--help`, `-h` — Show this help.
- `--target <target>` — Exact ID of a compatible target in the graph. Required.
- `--request <request>` — Explicit request; up to 4,096 characters, without secrets. Required.
