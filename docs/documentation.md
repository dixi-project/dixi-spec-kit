# DIXI Spec Kit documentation

## Purpose

List everything written for people who use DIXI, by what you want to do. Each line says what you will find, so that you open one page and not five.

## Start

- [README](../README.md): what DIXI is, how to install it and the first commands.
- [Command guide](command-catalog.md): the path of a feature from an idea to a release, and a complete example from `dixi init`.
- [Support matrix](support-matrix.md): which systems, Python versions and agents are supported, and with what evidence.

## Choose a command

- [Command guide](command-catalog.md): a table of which command to use at each moment, for the thirty-three operations.
- [Recipes](workflow-quickstart.md): the same operations from the terminal, without an agent, with `dixi workflow`.

## Look up a command or an option

- [Command reference](commands/index.md): one page per operation that runs inside the agent, with its steps, limits and an example.
- [CLI reference](cli/index.md): one page per terminal command, with every option and the exit codes.
- [Subagents](subagents.md): the four roles installed for Claude Code, what each one does and where it stops.

## Extend the kit

- [Automatic controls](controls.md): the five hooks that `--controls` installs, what each one blocks and what none of them covers.
- [Extensions and presets](extensions-and-presets.md): add operations of your own, or replace the kit's texts with your team's, from a local folder.

## Migrate

- [Coming from Spec Kit](coming-from-spec-kit.md): the same steps under DIXI's names, and how to move an existing project.
- [Comparison with Spec Kit](spec-kit-comparison.md): dated and sourced, with what DIXI still lacks.

## Contribute

- [Contributing](../CONTRIBUTING.md): how to propose a change and what a pull request must carry.
- [Local development](local-development.md): build and test the kit from source.
- [Roadmap](../ROADMAP.md) and [changelog](../CHANGELOG.md): what each version includes and what comes next.
