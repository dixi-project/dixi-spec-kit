# Documentación de DIXI Spec Kit

## Propósito

Listar todo lo escrito para quienes usan DIXI, según lo que quieres hacer. Cada línea dice qué vas a encontrar, para que abras una página y no cinco.

## Empezar

- [README](../README.es.md): qué es DIXI, cómo instalarlo y los primeros comandos.
- [Guía de comandos](command-catalog.es.md): el camino de una feature, de una idea a una versión, y un ejemplo completo desde `dixi init`.
- [Matriz de soporte](support-matrix.md) (en inglés, con resumen en español): qué sistemas, versiones de Python y agentes están soportados, y con qué evidencia.

## Elegir un comando

- [Guía de comandos](command-catalog.es.md): una tabla de qué comando usar en cada momento, para las treinta y tres operaciones.
- [Recetas](workflow-quickstart.es.md): las mismas operaciones desde la terminal, sin agente, con `dixi workflow`.

## Consultar un comando o una opción

- [Referencia de comandos](commands/index.es.md): una página por cada operación que se ejecuta dentro del agente, con sus pasos, sus límites y un ejemplo.
- [Referencia de la CLI](cli/index.es.md): una página por cada comando de terminal, con todas las opciones y los códigos de salida.
- [Subagentes](subagents.es.md): los cuatro roles que se instalan para Claude Code, qué hace cada uno y dónde se detiene.

## Extender el kit

- [Controles automáticos](controls.es.md): los cinco hooks que instala `--controls`, qué bloquea cada uno y qué no cubre ninguno.
- [Extensiones y presets](extensions-and-presets.es.md): añade operaciones propias, o sustituye los textos del kit por los de tu equipo, desde una carpeta local.

## Migrar

- [Si vienes de Spec Kit](coming-from-spec-kit.es.md): los mismos pasos con los nombres de DIXI, y cómo mover un proyecto existente.
- [Comparación con Spec Kit](spec-kit-comparison.md) (en inglés): fechada y con fuentes, con lo que a DIXI todavía le falta.

## Contribuir

- [Cómo contribuir](../CONTRIBUTING.md) (en inglés): cómo plantear un cambio y qué debe llevar un pull request.
- [Desarrollo local](local-development.md) (en inglés, con resumen en español): construir y probar el kit desde el código.
- [Roadmap](../ROADMAP.md) y [changelog](../CHANGELOG.md) (en inglés): qué incluye cada versión y qué viene después.
