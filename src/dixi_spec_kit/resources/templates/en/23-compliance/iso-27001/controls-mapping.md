# ISO/IEC 27001 controls mapping

> **Working aid, not legal advice.** This working table maps the project's controls to the themes of the ISO/IEC 27001 reference control set. It does not reproduce the standard's text and no template certifies compliance.

## Purpose

Prepare the statement of applicability: for each reference control the team records whether it applies, why, how the project implements it and where the evidence is. Use the control identifiers from your licensed copy of the standard.

## Rules

- Exclusions need a reason tied to scope or risk, never "not done yet".
- Implementation is described in the project's own words with a link to the artifact.
- One project control can support several reference controls; reuse its ID.
