# Content strategy

## Purpose

Define what content the project publishes, for whom, in which languages, and how it is planned, written, reviewed, localised and retired. Content serves real questions from the audience; volume is not a goal.

## Production process

1. Idea backed by research, search intent or support questions.
2. Brief: goal, audience, language, primary question, outline, internal links, call to action.
3. Draft following the content guidelines.
4. Review for accuracy, tone, accessibility and claims that need evidence.
5. Localisation per market (see below).
6. Publication on the language-prefixed URL with canonical and `hreflang`.
7. Measurement and scheduled review.

## Brief checklist

- [ ] Goal and success metric.
- [ ] Persona and their question.
- [ ] Primary and related search intents per language.
- [ ] Outline with headings.
- [ ] Internal links to related pages in the same language.
- [ ] One call to action.

## Localisation, not literal translation

- Adapt examples, units, currencies, dates and references to each market.
- Research search terms per language instead of translating keywords.
- Keep the same page structure so alternates stay equivalent.
- A native or fluent reviewer approves each language version.
- If a language version is not ready, do not publish an untranslated copy under that language's URL.
